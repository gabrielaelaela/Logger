# Logger Library

Библиотека для записи текстовых сообщений в журнал с поддержкой разных уровней важности и консольное многопоточное приложение для демонстрации работы библиотеки.

## Возможности

### Библиотека логирования

Реализована библиотека для записи сообщений в текстовый файл.

Поддерживаемые уровни важности:

- `Info` — информационное сообщение
- `Warning` — предупреждение
- `Error` — ошибка

В журнал сохраняется:

- время получения сообщения;
- уровень важности;
- текст сообщения.

Функциональность:

- установка уровня важности по умолчанию при создании логгера;
- изменение уровня важности по умолчанию после инициализации;
- фильтрация сообщений: сообщения с уровнем ниже заданного не записываются;
- поддержка расширения через базовый интерфейс логгера.

## Архитектура

Библиотека построена с использованием интерфейса и базового класса:

```
ILogger
   |
   |
ALogger
   |
   |
FileLogger
```

### ILogger

Интерфейс логгера, определяющий основные операции:

- запись сообщения;
- изменение уровня важности по умолчанию.

### ALogger

Базовый класс, содержащий общую логику:

- хранение уровня важности по умолчанию;
- преобразование уровня важности в строковое представление;
- преобразование строки в уровень важности.

### FileLogger

Реализация логгера с записью в текстовый файл.

## Консольное приложение

Приложение демонстрирует работу библиотеки.

Возможности:

- получение сообщений от пользователя через консоль;
- указание уровня важности сообщения;
- передача сообщений в отдельный поток записи;
- потокобезопасная очередь сообщений;
- асинхронная запись логов в файл.

Используемые механизмы многопоточности:

- `std::thread`
- `std::mutex`
- `std::condition_variable`
- `std::queue`

## Требования

- C++17 или выше
- CMake 3.10+

## Сборка

Клонировать репозиторий:

```bash
git clone <repository_url>
cd <project_directory>
```

Создать директорию для сборки:

```bash
mkdir build
cd build
```

Сгенерировать файлы сборки:

```bash
cmake ..
```

Собрать проект:

```bash
cmake --build .
```

## Запуск

Приложение принимает два параметра:

1. имя файла журнала;
2. уровень важности по умолчанию.

Пример:

```bash
./LoggerApp logs.txt Info
```

После запуска приложение ожидает ввод сообщений:

```
Enter the log message (or 'end'): Server started
Enter the priority level (Info, Warning, Error): Info
```

Для завершения работы:

```
end
```

2026-07-26 20:16:10    [WARNING]   Connection timeout
