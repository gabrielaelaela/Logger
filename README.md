# Logger Library

Библиотека для записи текстовых сообщений в журнал с поддержкой разных уровней важности и консольное многопоточное приложение для демонстрации работы библиотеки.

## Библиотека логирования

Реализована библиотека для записи сообщений с использованием различных типов логгеров.

Поддерживаемые уровни важности:

- `Info` — информационное сообщение
- `Warning` — предупреждение
- `Error` — ошибка

Поддерживаемые реализации:

- `FileLogger` — запись сообщений в текстовый файл;
- `SocketLogger` — отправка сообщений через TCP-соединение.

В журнале сохраняется:

- время получения сообщения;
- уровень важности;
- текст сообщения.

Функциональность:

- установка уровня важности по умолчанию при создании логгера;
- изменение уровня важности после инициализации;
- фильтрация сообщений: сообщения с уровнем ниже заданного не записываются;
- проверка корректности инициализации логгера;
- единый интерфейс для разных способов записи.

## Архитектура

Библиотека построена с использованием интерфейса и базового класса:

```
             ILogger
                |
                |
             ALogger
             /      \
            /        \
   FileLogger    SocketLogger
```

### ILogger

Интерфейс логгера, определяющий основные операции:

- запись сообщения;
- изменение уровня важности по умолчанию;
- проверка готовности логгера к работе.

### ALogger

Базовый класс, содержащий общую логику:

- хранение уровня важности по умолчанию;
- изменение уровня важности;
- преобразование уровня важности в строковое представление;
- преобразование строки в уровень важности.

### FileLogger

Реализация логгера с записью сообщений в текстовый файл.

### SocketLogger

Реализация логгера с отправкой сообщений через TCP-сокет.

Для работы требуется запущенный сервер, принимающий TCP-соединения и сообщения от логгера.

## Консольное приложение

Приложение демонстрирует работу библиотеки.

Возможности:

- выбор уровня важности по умолчанию;
- выбор типа логгера (`File` или `Socket`);
- ввод сообщений через консоль;
- указание уровня важности сообщения;
- передача сообщений в отдельный поток записи;
- потокобезопасная очередь сообщений;
- асинхронная запись логов.

Используемые механизмы многопоточности:

- `std::thread`
- `std::mutex`
- `std::condition_variable`
- `std::queue`
- `std::atomic`

## Требования

- C++17 или выше
- CMake 3.10+
- GCC
- Linux (Ubuntu/Debian)

## Сборка

Клонировать репозиторий:

```bash
git clone <repository_url>
cd <project_directory>
```

Создать директорию для сборки:

```bash
mkdir build
cd build
```

Сгенерировать файлы сборки:

```bash
cmake ..
```

Собрать проект:

```bash
cmake --build .
```

## Запуск

После запуска приложения необходимо выбрать:

1. уровень важности по умолчанию;
2. тип логгера.

Пример:

```
Choose default priority (Enter I for Info, W for Warning or E for Error): I

Choose logger type (enter F for File or S for Socket): F

Enter filename: logs.txt
```

После этого приложение ожидает ввод сообщений:

```
Enter the log message (or 'end'): Server started
Enter the priority level (Info, Warning, Error): Info
```

Для завершения работы:

```
end
```
